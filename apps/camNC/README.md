# camNC app

Main application that overlays CNC G-code on a live, calibrated camera feed.
Built with TanStack Start, React and react-three-fiber. See
[docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) for an overview.

## Development

```bash
cp .env.example .env.local   # and fill in the values
pnpm dev --filter @wbcnc/camNC   # from the repo root
```

- `pnpm test` – browser tests (Vitest + Playwright/Chromium).
- `pnpm run push-db` – push the Drizzle schema (`src/db/schema.ts`) to `DATABASE_URL`.

`src/routeTree.gen.ts` is generated by the TanStack Router plugin; don't edit it.
